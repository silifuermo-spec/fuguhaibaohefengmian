# 验收标准

先检查硬门槛，再评分。任一硬门槛失败即不通过，必须针对最大偏差重新生成或进行确定性文字合成。

## 共享硬门槛

- 角色源图明确来自 `$fugumaozhan` 的五张内置动作版参考图流程，并已通过该 Skill 验收；不是纯提示词生成角色。
- 成品为竖幅 3:4，只有一个人类角色来源和一个八音盒，无多余人物、肢体、重复手脚、反向关节、穿透或关键裁切。
- 角色仍能与源图对应：身份、面孔、发型、服装、鞋履、职业道具、主色和毛毡定格材质未漂移。
- 羊毛毡、粗针织、灯芯绒、棉麻、旧皮革、缝线、陶土颗粒、木纹与做旧金属具有可触摸感；不是普通 3D 卡通、光滑塑料或真人摄影。
- 背景、照明、纸张或织物质感与八张样片属于同一低饱和复古视觉家族，无霓虹、廉价渐变、忙乱场景或水印。

## 海报硬门槛

- `Skill Design` 拼写完全正确、可读，固定在顶部中央并保持两行层叠、连笔长尾、缝线软垫式造型与样片尺度；颜色可以跟随角色穿搭。
- 完整全身角色位于中央，头顶、双手、手指、双脚和必要道具均在画内；动作夸张但至少一只脚真实承重。
- 角色站在一个打开的八音盒上；盒盖、内垫、盒体和短脚完整可见，支撑脚有压缩和接触阴影。
- `Ai Studio` 拼写完全正确、可读，固定在右下角，未被人物、装饰或八音盒遮挡。
- 左右装饰与角色职业相关、尺寸从属、分布有节奏；不默认套用音符，不遮挡任何关键内容。

## 封面硬门槛

- 只出现一条从顶部进入的小腿和一只脚；脚真实踩在一个闭合八音盒顶面中央。
- 闭合八音盒位于中上部中央、完整稳定；左右有镜像式文案空间，不得打开或移动到下半部。
- 左上恰有 5 个角色色板圆点。
- 超大单行 `Ai Studio` 拼写完全正确、可读，固定在下半部；角色化织物填充、连续外轮廓、内侧立体绳线/滚边/缝线三部分同时存在。两层描边沿所有字形外边缘和内字腔完整闭合、粗细均匀，颜色从当前角色色板派生并与填充及背景形成清楚明度差；不得固定套用样片的具体描边色相。无描边或只有单层普通描边即为硬门槛失败。
- 左右小文案与底部三栏文本可读、与角色相关、无乱码和 lorem ipsum；三栏均左对齐且不与标题重叠。

## 评分

每项 0–2 分，总分至少 18/20；“角色来源与一致性”“手工材质”“模式版式”“受力关系”和“固定文字”必须为 2 分。

| 项目 | 2 分标准 |
| --- | --- |
| 角色来源与一致性 | 可追溯到通过验收的 fugumaozhan 输出，人物身份和服装未漂移 |
| 手工材质 | 毛毡、织物、陶土、皮革、木材、金属和缝线清晰可触摸 |
| 模式版式 | 海报或封面的固定网格、层级、尺寸关系与样片一致 |
| 受力关系 | 脚与盒面真实接触，重心、软垫压缩和阴影可信 |
| 固定文字 | 所有固定文字拼写正确、可读、位置尺度固定且材质协调；封面 `Ai Studio` 具备角色色板派生的连续外轮廓与内侧立体绳线/滚边/缝线，未固定复制样片色相 |
| 角色动作或裁切 | 海报全身动态强；封面单腿裁切准确，无多余身体部分 |
| 八音盒 | 开合状态正确、结构完整、位于固定锚点，材质与角色协调 |
| 装饰或编辑文案 | 海报装饰角色相关；封面文案角色相关且网格正确 |
| 色彩与背景 | 从角色穿搭派生、低饱和、有足够对比且无色彩漂移 |
| 构图完成度 | 主体够大、留白舒适、无遮挡、无关键裁切和无杂乱 |

## 迭代顺序

1. 角色来源或身份漂移。
2. 开合状态、脚与八音盒的承重关系。
3. 海报完整全身或封面单腿裁切。
4. 固定文字的拼写、位置、尺度、可读性，以及封面标题双层手工描边的完整性与角色化配色。
5. 毛毡定格材质和复古低饱和色彩。
6. 装饰、文案和微小细节。

每轮只修正得分最低的一项，并保留已经通过的角色、构图、八音盒、标题和色彩不变量。重新生成时继续传入角色源图和当前模式全部四张样片。
